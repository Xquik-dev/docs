## Copy-ready X tasks

Use these after you create an API key. Each call returns JSON you can send to an app, agent, spreadsheet job, webhook worker, or dashboard.

### Search tweets

Returns `tweets`, `has_next_page`, and `next_cursor`. Search supports X operators such as `from:username`, `since:YYYY-MM-DD`, `until:YYYY-MM-DD`, `#hashtag`, quoted phrases, and `OR`. Cost: 1 credit per tweet returned.

```bash
curl -G https://xquik.com/api/v1/x/tweets/search \
  --data-urlencode "q=from:username giveaway" \
  --data-urlencode "queryType=Latest" \
  --data-urlencode "limit=50" \
  -H "x-api-key: xq_your_api_key_here" | jq
```

```json
{
  "tweets": [
    {
      "id": "1780000000000000000",
      "text": "Giveaway entry is open.",
      "createdAt": "2026-05-08T04:00:00Z",
      "likeCount": 42,
      "retweetCount": 5,
      "replyCount": 3,
      "author": {
        "id": "9876543210",
        "username": "username",
        "name": "Xquik"
      }
    }
  ],
  "has_next_page": true,
  "next_cursor": "DAACCgACGRElMJcAAA"
}
```

### List followers

Returns `users`, `has_next_page`, and `next_cursor`. Use `pageSize` to cap each page between 20 and 200 users. Cost: 1 credit per follower returned.

```bash
curl -G https://xquik.com/api/v1/x/users/username/followers \
  --data-urlencode "pageSize=50" \
  -H "x-api-key: xq_your_api_key_here" | jq
```

```json
{
  "users": [
    {
      "id": "9876543210",
      "username": "username",
      "name": "Xquik",
      "followers": 10000,
      "following": 500,
      "verified": true
    }
  ],
  "has_next_page": true,
  "next_cursor": "DAACCgACGRElMJcAAA"
}
```

### Upload media from a URL

Returns `mediaId` for DMs and `mediaUrl` for tweet `media` arrays. URL uploads are useful for agents and workflow tools that pass files by HTTPS URL. Cost: 10 credits per upload.

```bash
curl -X POST https://xquik.com/api/v1/x/media \
  -H "x-api-key: xq_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"account": "myxhandle", "url": "https://example.com/image.png"}' | jq
```

```json
{
  "success": true,
  "mediaId": "1893726451023847424",
  "mediaUrl": "https://media.xquik.com/uploads/1893726451023847424.png"
}
```

## Use Xquik with AI agents

Give agents a docs index first, then choose the execution path:

- Use [llms.txt](/llms.txt) when an agent needs to find the right API, SDK, MCP, webhook, or billing page.
- Use the [Context7 library](https://context7.com/xquik-dev/xquik-docs) when your coding environment supports Context7 docs lookup.
- Install the [Xquik Skill](https://github.com/Xquik-dev/x-twitter-scraper) when the agent writes code for tweet search, follower exports, media uploads, DMs, monitors, or webhooks.
- Connect API MCP v2.5.3 at `https://xquik.com/mcp` when an agent should run authenticated tasks through Streamable HTTP. Use the [current client compatibility path](/mcp/overview#client-compatibility) for OAuth, API-key fallback, or an adapter. Full credentials expose 118 operations. Guest `paid_reads` keys expose 33 eligible GET routes.

```bash
npx skills add Xquik-dev/x-twitter-scraper
```

## For developers

Xquik provides 6 integration methods:

<Steps>
  <Step title="REST API v1">
    Create monitors, query events, and manage webhooks programmatically. Authenticate with API keys via the `x-api-key` header.
  </Step>
  <Step title="HMAC Webhooks">
    Receive real-time event notifications at your HTTPS endpoints. Every delivery is signed with SHA-256 HMAC for verification.
  </Step>
  <Step title="MCP Server">
    Connect AI agents through API MCP v2.5.3. Use OAuth 2.1 where supported or the [documented client-specific fallback](/mcp/overview#client-compatibility). Streamable HTTP exposes 2 code-mode tools: `explore` searches the catalog and `xquik` runs authenticated calls with normalized snake_case results.
  </Step>
  <Step title="AI Agent Skill">
    Install the [Xquik Skill](https://github.com/Xquik-dev/x-twitter-scraper) to give 40+ AI coding agents (Claude Code, Cursor, Codex, Copilot, Windsurf, and more) deep knowledge of the Xquik API, MCP tools, and 126 REST operations. Install via `npx skills add Xquik-dev/x-twitter-scraper`.
  </Step>
  <Step title="Guest Wallets">
    Prepay the 33 eligible GET routes without an account. Ask the user to confirm $10-$250 USD, create a Stripe-hosted Payment Link through REST, then wait for a verified Stripe webhook before using the `paid_reads` key.
  </Step>
  <Step title="Machine Payments Protocol">
    Pay per API call without subscribing. Seven fixed-price read operations accept MPP payments through Tempo (USDC). See the [MPP overview](/mpp/overview) for operations and pricing.
  </Step>
</Steps>
