<CodeGroup>
  ```bash cURL
  curl "https://xquik.com/api/v1/x/tweets/1893456789012345678/retweeters" \
    -H "x-api-key: xq_YOUR_KEY_HERE" | jq
  ```

  ```javascript Node.js
  const tweetId = "1893456789012345678";
  const response = await fetch(`https://xquik.com/api/v1/x/tweets/${tweetId}/retweeters`, {
    headers: { "x-api-key": "xq_YOUR_KEY_HERE" },
  });
  const data = await response.json();
  const retweeterRows = data.users.map((user) => ({
    source_tweet_id: tweetId,
    retweeter_id: user.id,
    username: user.username,
    display_name: user.name,
    follower_count: user.followers ?? null,
    following_count: user.following ?? null,
    verified: user.verified ?? false,
    profile_image_url: user.profilePicture ?? null,
  }));
  const nextCursor = data.has_next_page ? data.next_cursor : null;

  for (const row of retweeterRows) {
    const output = { ...row, next_cursor: nextCursor };
    process.stdout.write(`${JSON.stringify(output)}\n`);
  }
  ```

  ```python Python
  import json
  import requests

  response = requests.get(
      "https://xquik.com/api/v1/x/tweets/1893456789012345678/retweeters",
      headers={"x-api-key": "xq_YOUR_KEY_HERE"},
  )
  data = response.json()
  next_cursor = data["next_cursor"] if data["has_next_page"] else None
  retweeter_rows = [
      {
          "source_tweet_id": "1893456789012345678",
          "retweeter_id": user["id"],
          "username": user["username"],
          "display_name": user["name"],
          "follower_count": user.get("followers"),
          "following_count": user.get("following"),
          "verified": user.get("verified", False),
          "profile_image_url": user.get("profilePicture"),
          "next_cursor": next_cursor,
      }
      for user in data["users"]
  ]
  for row in retweeter_rows:
      print(json.dumps(row))
  ```
</CodeGroup>

Use `GET /x/tweets/{id}/retweeters` when a workflow needs one row per account
that reposted a tweet for giveaway checks, CRM enrichment, audience analysis,
or follow-up jobs. Store `source_tweet_id`, `retweeter_id`, `username`,
`display_name`, `follower_count`, `following_count`, `verified`,
`profile_image_url`, and
`next_cursor` instead of logging the full page response.

## Path parameters

<ParamField path="id" type="string" required>
  Tweet ID (numeric string).
</ParamField>

## Query parameters

<ParamField query="cursor" type="string">
  Pagination cursor from a previous response. Omit for the first page.
</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key. Session cookie authentication is also supported.
</ParamField>
