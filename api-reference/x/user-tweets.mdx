  # Page 2 - pass next_cursor from the previous response
  curl -G https://xquik.com/api/v1/x/users/44196397/tweets \

  ```javascript Node.js
  const userId = "44196397";
  const response = await fetch(`https://xquik.com/api/v1/x/users/${userId}/tweets`, {
    headers: { "x-api-key": "xq_YOUR_KEY_HERE" },
  });
  const data = await response.json();
  console.log(data.tweets);

  // Paginate
  if (data.has_next_page) {
    const next = await fetch(
      `https://xquik.com/api/v1/x/users/${userId}/tweets?cursor=${data.next_cursor}`,
      { headers: { "x-api-key": "xq_YOUR_KEY_HERE" } },
    );
    const page = await next.json();
    console.log(page.tweets);
  }
  ```

  ```python Python
  import requests

  response = requests.get(
      "https://xquik.com/api/v1/x/users/44196397/tweets",
      headers={"x-api-key": "xq_YOUR_KEY_HERE"},
  )
  data = response.json()
  print(data["tweets"])

  # Paginate
  while data["has_next_page"]:
      data = requests.get(
          "https://xquik.com/api/v1/x/users/44196397/tweets",
          params={"cursor": data["next_cursor"]},
          headers={"x-api-key": "xq_YOUR_KEY_HERE"},
      ).json()
      print(data["tweets"])
  ```

## Path parameters

<ParamField path="id" type="string" required>
  X user ID (numeric string) or username.
</ParamField>

## Query parameters

<ParamField query="cursor" type="string">
  Pagination cursor. Pass the `next_cursor` value from the previous response to fetch the next page.
</ParamField>

<ParamField query="includeReplies" type="boolean" default="false">
  Include reply tweets in results. Defaults to `false` (original tweets only).
</ParamField>

<ParamField query="includeParentTweet" type="boolean" default="false">
  Include the parent tweet for replies. Defaults to `false`.
</ParamField>

### Tweet result filters

These optional filters apply to `tweets[]` returned by this route. They keep the
same user target and filter rows after each page is fetched, so selective
filters can return fewer rows than an unfiltered page.
