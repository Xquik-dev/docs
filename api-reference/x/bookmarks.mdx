  ```javascript Node.js
  const bookmarkFolderId = ""; // Set to a folder ID to export one folder.
  const baseUrl = "https://xquik.com/api/v1/x/bookmarks";
  let pageCursor = "";

  for (let pageIndex = 0; pageIndex < 3; pageIndex += 1) {
    const params = new URLSearchParams();
    if (bookmarkFolderId !== "") params.set("folderId", bookmarkFolderId);
    if (pageCursor !== "") params.set("cursor", pageCursor);

    const query = params.toString();
    const response = await fetch(query === "" ? baseUrl : `${baseUrl}?${query}`, {
      headers: { "x-api-key": "xq_YOUR_KEY_HERE" },
    });
    const page = await response.json();
    if (!response.ok) throw new Error(JSON.stringify(page));

    const bookmarkRows = page.tweets.map((tweet) => ({
      bookmark_source: bookmarkFolderId === "" ? "all_bookmarks" : "folder",
      folder_id: bookmarkFolderId || null,
      tweet_id: tweet.id,
      tweet_url: tweet.url ?? null,
      text: tweet.text,
      author_id: tweet.author?.id ?? null,
      author_username: tweet.author?.username ?? null,
      author_name: tweet.author?.name ?? null,
      author_followers: tweet.author?.followers ?? null,
      author_verified: tweet.author?.verified ?? null,
      author_profile_picture: tweet.author?.profilePicture ?? null,
      created_at: tweet.createdAt ?? null,
      like_count: tweet.likeCount ?? null,
      reply_count: tweet.replyCount ?? null,
      retweet_count: tweet.retweetCount ?? null,
      quote_count: tweet.quoteCount ?? null,
      view_count: tweet.viewCount ?? null,
      media_urls: (tweet.media ?? []).map((item) => item.mediaUrl).filter(Boolean),
      page_index: pageIndex,
      page_cursor: pageCursor,
      next_cursor: page.next_cursor,
      has_next_page: page.has_next_page,
    }));
    for (const row of bookmarkRows) process.stdout.write(`${JSON.stringify(row)}\n`);

    if (!page.has_next_page || page.next_cursor === "") break;
    pageCursor = page.next_cursor;
  }
  ```

  ```python Python
  import json
  import requests

  bookmark_folder_id = ""  # Set to a folder ID to export one folder.

              "folder_id": bookmark_folder_id or None,

              "tweet_url": tweet.get("url"),
              "text": tweet["text"],
              "author_id": (tweet.get("author") or {}).get("id"),
              "author_username": (tweet.get("author") or {}).get("username"),
              "author_name": (tweet.get("author") or {}).get("name"),
              "author_followers": (tweet.get("author") or {}).get("followers"),
              "author_verified": (tweet.get("author") or {}).get("verified"),
              "author_profile_picture": (tweet.get("author") or {}).get("profilePicture"),
              "created_at": tweet.get("createdAt"),
              "like_count": tweet.get("likeCount"),
              "reply_count": tweet.get("replyCount"),
              "retweet_count": tweet.get("retweetCount"),
              "quote_count": tweet.get("quoteCount"),
              "view_count": tweet.get("viewCount"),
              "media_urls": [
  ```

## Bookmarks handoff

Use `GET /x/bookmarks` when a reading list, CRM, research queue, or agent needs
saved tweets from the authenticated account. The examples write JSON Lines rows
with bookmark source, folder ID, tweet ID, tweet URL, text, author ID,
username, display name, follower count, verified state, profile image URL,
engagement counts, media URLs, and cursor fields. Store the last saved
`next_cursor` per folder so each bookmark export can resume without duplicating
earlier rows.

## Organize a bookmark export

Use bookmarks for tweets saved by the authenticated account. Keep the account
identity and collection time with every tweet.

Export tweet ID, text, author, creation time, engagement counts, and media
URLs. Preserve the folder context when the response supplies it.

Bookmarks can support research queues, reading lists, or approved archives.
They are different from public likes. Do not expose saved tweets to another
user without authorization.

Paginate in cursor order. Save each page before advancing. Deduplicate resumed
exports by account and tweet ID.

Use bookmark folders to discover folder structure. Use the home timeline for
the account’s feed. These routes represent different collections.

## Preserve bookmark privacy

Treat saved tweets as account-scoped content. Limit exports to the authorized
workflow and intended reviewers.

Store the account identifier outside shared filenames. Avoid placing private
folder names in public logs or URLs.

Delete temporary files after the approved handoff completes. Keep only the
records required by the workflow.

| Bookmark library column | Response source | Account-scoped rule |
| --- | --- | --- |
| `connected_account_id` | Authenticated account context | Keep bookmarks isolated from every other connected account. |
| `folder_id` | Requested `folderId` | Preserve the bookmark folder when one was requested. |
| `tweet_id` | `tweets[].id` | De-duplicate saved tweets inside the same account and folder. |
| `tweet_url` | `tweets[].url` | Open the original tweet during approved review. |
| `text` | `tweets[].text` | Preserve the saved tweet body without reviewer edits. |
| `author_id` | `tweets[].author.id` | Keep a stable original-author key. |
| `author_username` | `tweets[].author.username` | Display the author handle observed during collection. |
| `created_at` | `tweets[].createdAt` | Preserve when the tweet was published. |
| `media_urls` | `tweets[].media[].mediaUrl` | Keep image and video context beside the saved tweet. |
| `page_cursor` | Request `cursor` | Prove which bookmark page produced the row. |
| `next_cursor` | Response `next_cursor` | Resume only after the current bookmark page is stored. |
| `collected_at` | Integration timestamp | Audit when the authorized export observed the bookmark. |

| Privacy control | Required scope | Safe handling |
| --- | --- | --- |
| Export owner | Connected account ID | Reject a handoff that targets another account. |
| Folder label | Authorized account and folder ID | Keep private folder names out of public logs and URLs. |
| Temporary file | One approved review or import | Delete it after the handoff completes. |
| Shared storage | Explicit authorized reviewers | Store only required bookmark fields and access controls. |
| Public output | None by default | Do not publish account bookmarks or folder names. |

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```
Missing or invalid API key.

### 402 Insufficient credits

```json
{ "error": "insufficient_credits" }
```
Metered access requires enough available credits. Possible error values include `no_subscription`, `subscription_inactive`, `no_credits`, and `insufficient_credits`.

### 429 Rate Limit Exceeded

```json
{
  "error": "rate_limit_exceeded",
  "message": "Too many requests. Try again later.",
  "retryAfter": 60
}
```
The API key, user, or plan tier is sending requests too quickly. Respect the `Retry-After` header before retrying.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```
The read service returned an error. Retry after a short delay.

### 424 Dependency Failed

```json
{ "error": "x_api_unavailable" }
```
Returned when you opt into the normalized v1 response contract and the read service is unavailable.
