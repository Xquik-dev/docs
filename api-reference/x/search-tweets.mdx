  const params = new URLSearchParams({ q: "from:xquikcom giveaway" });
  const response = await fetch(`https://xquik.com/api/v1/x/tweets/search?${params}`, {
    headers: { "x-api-key": "xq_YOUR_KEY_HERE" },
  });
  const data = await response.json();
  console.log(data.tweets);

  // Paginate through all results
  let cursor = data.next_cursor;
  while (data.has_next_page) {
    const next = await fetch(
      `https://xquik.com/api/v1/x/tweets/search?${new URLSearchParams({ q: "from:xquikcom giveaway", cursor })}`,

    console.log(page.tweets);
    if (!page.has_next_page) break;
    cursor = page.next_cursor;
  }

## Direct API handoff

Use `GET /x/tweets/search` when an app, queue worker, CRM enrichment job, or agent needs the latest matching tweets without creating a stored extraction job. It is the fastest path for live search pages, JSON ingestion, and small CSV or XLSX projections. For large file exports with a saved job, use [`tweet_search_extractor`](/guides/tweet-search-export) instead.

`limit` is an upper bound from 1 to 200. Omit it for a single page, or pass it when you want Xquik to page internally up to the requested count. For cursor pagination, pass the previous response's `next_cursor` as `cursor`.

Tweet search costs 1 credit per tweet returned. Low credit balances can return fewer tweets than `limit`; zero affordable results return `402 insufficient_credits`. Retry `429` with the `Retry-After` header, and retry `424` or `502` after a short backoff.

## Query parameters

<ParamField query="q" type="string" required>
  Search query. Supports X search operators such as `from:username`, `to:username`, `#hashtag`, and boolean operators.
</ParamField>

<ParamField query="queryType" type="string">
  Sort order for search results. `Top` returns most relevant tweets, `Latest` returns most recent. Defaults to `Latest`.
</ParamField>

<ParamField query="cursor" type="string">
  Pagination cursor. Pass the `next_cursor` value from the previous response to fetch the next page.
</ParamField>

<ParamField query="sinceTime" type="string">
  Filter tweets published after this date. Uses X search `since:` operator format (e.g. `2026-03-01`).
</ParamField>

<ParamField query="untilTime" type="string">
  Filter tweets published before this date. Uses X search `until:` operator format (e.g. `2026-03-27`).
</ParamField>

<ParamField query="limit" type="integer">
  Maximum number of tweets to return per page (1-200, default 20). Use with cursor-based pagination to control page size.
</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key. Session cookie authentication is also supported.
</ParamField>
