  const baseUrl = "https://xquik.com/api/v1/x/timeline";
  const seenTweetIds = new Set();
  let pageCursor = "";

  for (let pageIndex = 0; pageIndex < 3; pageIndex += 1) {
    const params = new URLSearchParams();

    const query = params.toString();

        text: tweet.text,
        author_id: tweet.author?.id ?? null,
        author_username: tweet.author?.username ?? null,
        author_name: tweet.author?.name ?? null,
        author_followers: tweet.author?.followers ?? null,
        author_verified: tweet.author?.verified ?? null,
        author_profile_picture: tweet.author?.profilePicture ?? null,
        created_at: tweet.createdAt ?? null,
        is_reply: tweet.isReply ?? false,
        in_reply_to_id: tweet.inReplyToId ?? null,
        like_count: tweet.likeCount ?? null,
        reply_count: tweet.replyCount ?? null,
        retweet_count: tweet.retweetCount ?? null,
        quote_count: tweet.quoteCount ?? null,
        view_count: tweet.viewCount ?? null,
        media_urls: (tweet.media ?? []).map((item) => item.mediaUrl).filter(Boolean),
        page_index: pageIndex,
        page_cursor: pageCursor,
        next_cursor: page.next_cursor,
        has_next_page: page.has_next_page,
      };
    });
    for (const row of timelineRows) process.stdout.write(`${JSON.stringify(row)}\n`);

    if (!page.has_next_page || page.next_cursor === "") break;
    pageCursor = page.next_cursor;
  }

## Home timeline handoff

Use `GET /x/timeline` when an inbox, CRM, monitor seed job, or agent needs the
authenticated account's home feed. The examples write JSON Lines rows with
home timeline source, tweet ID, URL, text, author ID, username, display name,
follower count, verified state, profile image URL, reply context, engagement
counts, media URLs, `seenTweetIds`, and cursor fields. Store processed tweet
IDs and pass them as `seenTweetIds` with the last saved `next_cursor` to reduce
duplicates.

## Process the home timeline as a feed

Use this route for tweets visible in the authenticated account’s home
timeline. Keep the acting account and collection time beside every page.

Feed rows should preserve tweet ID, author, text, creation time, engagement
counts, media, and cursor. New tweets can change the first page between
requests.

Use timeline pages for inbox review, topic routing, or approved monitoring.
Do not describe the feed as a complete public archive. Ranking and source
availability affect what appears.

Deduplicate rows by tweet ID. Save each completed page before storing its next
cursor. Stop when the response has no next page.

Use bookmarks for saved tweets. Use user tweets for one profile’s public
timeline. Use tweet search for keyword, author, date, or media filters.

## Route timeline tweets by purpose

Apply explicit rules after collection. Route mentions to support review.
Route selected keywords to research. Route media tweets to asset review.

Keep the rule name and tweet ID with every decision. Do not replace the
original tweet text with a generated summary.

Reprocess a tweet only when its routing rule changes. This prevents repeated
notifications from overlapping timeline polls.

| Home timeline column | Response source | Feed use |
| --- | --- | --- |
| `account_id` | Connected account context | Keep one home feed isolated from every other connected account. |
| `tweet_id` | `tweets[].id` | De-duplicate timeline rows and build tweet URLs. |
| `tweet_url` | `tweets[].url` | Open the original tweet during inbox or CRM review. |
| `text` | `tweets[].text` | Apply support, research, campaign, or moderation rules. |
| `author_id` | `tweets[].author.id` | Keep a stable author key when usernames change. |
| `author_username` | `tweets[].author.username` | Display the current X handle. |
| `created_at` | `tweets[].createdAt` | Sort new home timeline tweets by creation time. |
| `in_reply_to_id` | `tweets[].inReplyToId` | Route tweet replies with their parent context. |
| `conversation_id` | `tweets[].conversationId` | Group tweets from the same conversation. |
| `media_urls` | `tweets[].media[].mediaUrl` | Send image and video tweets to asset review. |
| `page_cursor` | Request `cursor` | Prove which home timeline page produced the row. |
| `next_cursor` | Response `next_cursor` | Resume only after the current page is stored. |

| Routing rule | Concrete match | Destination |
| --- | --- | --- |
| Support reply | `isReply` plus an approved support account or keyword | Support review queue |
| Campaign mention | Campaign phrase in `text` | Campaign verification queue |
| Media review | Non-empty `media` | Image or video asset review |
| High-engagement tweet | Approved threshold on likes, replies, reposts, or views | Priority research queue |
| Saved author | `author.id` in an approved watchlist | CRM or analyst review |
| No rule match | No approved condition matches | Store without generating a notification |

## Query parameters

<ParamField query="cursor" type="string">
  Pagination cursor. Pass the `next_cursor` value from the previous response to fetch the next page.
</ParamField>

<ParamField query="seenTweetIds" type="string">
  Comma-separated tweet IDs to exclude from results. Empty entries are ignored. Use this to avoid returning tweets the user has already seen.
</ParamField>

### 401 Unauthenticated

```json
{ "error": "unauthenticated" }
```
Missing or invalid API key.

### 402 Insufficient credits

```json
{ "error": "insufficient_credits" }
```
Metered access requires enough available credits. Possible error values include `no_subscription`, `subscription_inactive`, `no_credits`, and `insufficient_credits`.

### 429 Rate Limit Exceeded

```json
{
  "error": "rate_limit_exceeded",
  "message": "Too many requests. Try again later.",
  "retryAfter": 60
}
```
The API key, user, or plan tier is sending requests too quickly. Respect the `Retry-After` header before retrying.

### 502 X API unavailable

```json
{ "error": "x_api_unavailable" }
```
The read service returned an error. Retry after a short delay.

### 424 Dependency Failed

```json
{ "error": "x_api_unavailable" }
```
Returned when you opt into the normalized v1 response contract and the read service is unavailable.
