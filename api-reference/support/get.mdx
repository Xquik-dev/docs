## Choose One Ticket History

Use this route when one ticket ID needs full message history. Use list for summaries across tickets. Use reply or update only when the conversation or status must change.

<Callout icon="circle-check" color="#16a34a">
  **Free** - does not consume credits
</Callout>
<Info>
  Support tickets are free for all authenticated users.
</Info>

| Support ticket history column | Response source | Review rule |
| --- | --- | --- |
| Ticket ID | `publicId` | Match the requested ticket before processing. |
| Ticket subject | `subject` | Keep the reported workflow visible. |
| Current state | `status` | Route open, in-progress, resolved, or closed tickets. |
| Message author | `messages[].sender` | Separate user and support replies. |
| Message text | `messages[].body` | Preserve the chronological investigation record. |
| Attachment state | `messages[].attachments[].status` | Download only ready attachments. |
| Updated at | `updatedAt` | Stop polling after the expected state arrives. |

## Path parameters

<ParamField path="id" type="string" required>
  The ticket public ID (e.g. `tkt_a1b2c3d4e5f6a1b2c3d4e5f6`). Returned when you [create a ticket](/api-reference/support/create) or [list tickets](/api-reference/support/list).
</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key. Session cookie authentication is also supported. Generate a key from the [dashboard](https://xquik.com/dashboard).
</ParamField>

## Response

### 200 OK

<ResponseField name="publicId" type="string">Unique ticket public ID.</ResponseField>
<ResponseField name="subject" type="string">Ticket subject.</ResponseField>
<ResponseField name="status" type="string">Current status: `open`, `in_progress`, `resolved`, or `closed`.</ResponseField>
<ResponseField name="createdAt" type="string">ISO 8601 creation timestamp.</ResponseField>
<ResponseField name="updatedAt" type="string">ISO 8601 last update timestamp.</ResponseField>
<ResponseField name="messages" type="object[]">Array of message objects, ordered chronologically.</ResponseField>
<ResponseField name="messages[].body" type="string">Message content.</ResponseField>
<ResponseField name="messages[].sender" type="string">Who sent the message: `user` or `support`.</ResponseField>
<ResponseField name="messages[].createdAt" type="string">ISO 8601 timestamp of when the message was sent.</ResponseField>
<ResponseField name="messages[].attachments" type="object[]">Private image and video attachments.</ResponseField>
<ResponseField name="messages[].attachments[].publicId" type="string">Attachment public ID.</ResponseField>
<ResponseField name="messages[].attachments[].filename" type="string">Original filename.</ResponseField>
<ResponseField name="messages[].attachments[].contentType" type="string">Validated media type.</ResponseField>
<ResponseField name="messages[].attachments[].kind" type="string">`image` or `video`.</ResponseField>
<ResponseField name="messages[].attachments[].sizeBytes" type="integer">File size in bytes.</ResponseField>
<ResponseField name="messages[].attachments[].status" type="string">`ready`, `pending`, or `failed`.</ResponseField>
<ResponseField name="messages[].attachments[].url" type="string">Authenticated download path.</ResponseField>

### 401 Unauthenticated

```json
{ "error": "unauthenticated", "message": "Authentication required. Provide a valid API key or bearer token." }
```
Missing or invalid API key.

### 404 Not Found

```json
{ "error": "not_found", "message": "Resource not found." }
```
No ticket exists with this ID, or it belongs to a different account.

### 429 Rate Limited

```json
{ "error": "rate_limit_exceeded", "message": "Too many requests. Try again later.", "retryAfter": 1 }
```
Wait for the `Retry-After` value before fetching the ticket again.
