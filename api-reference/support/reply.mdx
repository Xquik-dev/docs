Use JSON for text-only replies. Use `multipart/form-data` when attaching media.

<CodeGroup>
  ```bash cURL
  curl -X POST https://xquik.com/api/v1/support/tickets/tkt_a1b2c3d4e5f6a1b2c3d4e5f6/messages \
    -H "x-api-key: xq_YOUR_KEY_HERE" \
    -H "Content-Type: application/json" \
    -d '{
      "body": "That worked, thank you!"
    }' | jq
  ```

  ```javascript Node.js
  const ticketId = "tkt_a1b2c3d4e5f6a1b2c3d4e5f6";

    method: "POST",

  });

  ```


  ```go Go
  package main

  import (
      "bytes"

      })

      req, err := http.NewRequest("POST", "https://xquik.com/api/v1/support/tickets/"+ticketID+"/messages", bytes.NewReader(body))
      if err != nil {
          panic(err)
      }
      req.Header.Set("x-api-key", "xq_YOUR_KEY_HERE")
      req.Header.Set("Content-Type", "application/json")

      resp, err := http.DefaultClient.Do(req)
      if err != nil {
          panic(err)
      }
      defer resp.Body.Close()

      var data map[string]interface{}
      if err := json.NewDecoder(resp.Body).Decode(&data); err != nil {
          panic(err)
      }
      fmt.Println(data)
  }
  ```

## Path parameters

<ParamField path="id" type="string" required>
  The ticket public ID (e.g. `tkt_a1b2c3d4e5f6a1b2c3d4e5f6`). Returned when you [create a ticket](/api-reference/support/create) or [list tickets](/api-reference/support/list).
</ParamField>

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key. Session cookie authentication is also supported. Generate a key from the [dashboard](https://xquik.com/dashboard).
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Use `application/json` for text only. Use `multipart/form-data` for media.
</ParamField>

## Body

<ParamField body="body" type="string" required>
  Message content. 1-10,000 characters.
</ParamField>

<ParamField body="attachments" type="file[]">
  Up to 4 JPEG, PNG, GIF, WebP, MP4, MOV, or WebM files. The same per-file and 30 MB combined limits apply.
</ParamField>

For a media-only reply, omit `body` and include at least 1 attachment.

```bash cURL With Media
curl -X POST https://xquik.com/api/v1/support/tickets/tkt_a1b2c3d4e5f6a1b2c3d4e5f6/messages \
  -H "x-api-key: xq_YOUR_KEY_HERE" \
  -F "body=This recording shows the current behavior." \
  -F "attachments=@recording.mp4" | jq
```

## Response

<Tabs>
  <Tab title="201 Created">
    <ResponseField name="publicId" type="string">Ticket public ID the message was added to.</ResponseField>
    <ResponseField name="attachments" type="object[]">Created media receipts.</ResponseField>
    <ResponseField name="attachments[].publicId" type="string">Private attachment public ID.</ResponseField>
    <ResponseField name="attachments[].status" type="string">Upload status: `ready` or `failed`.</ResponseField>

    ```json
    {
      "publicId": "tkt_a1b2c3d4e5f6a1b2c3d4e5f6",
      "attachments": []
    }
    ```
  </Tab>
  <Tab title="400 Invalid Input">
    ```json
    { "error": "invalid_input", "message": "Invalid input. Check the request body." }
    ```
    Missing or invalid `body` field.
  </Tab>
  <Tab title="401 Unauthenticated">
    ```json
    { "error": "unauthenticated", "message": "Authentication required. Provide a valid API key or bearer token." }
    ```
    Missing or invalid API key.
  </Tab>
  <Tab title="404 Not Found">
    ```json
    { "error": "not_found", "message": "Resource not found." }
    ```
    No ticket exists with this ID, or it belongs to a different account.
  </Tab>
  <Tab title="429 Rate Limited">
    ```json
    { "error": "rate_limit_exceeded", "message": "Too many requests. Try again later.", "retryAfter": 60 }
    ```
    Wait for the `Retry-After` value before adding another reply.
  </Tab>
</Tabs>
