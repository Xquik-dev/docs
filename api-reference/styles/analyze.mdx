## Choose Style Analysis

Use this route to create or refresh a cached writing-style profile. Fresh cached profiles can return without another X fetch. Use list or get only when an existing cache should remain unchanged.

## Build a Reusable Tweet Writing Profile

Send one X username to analyze that profile's recent tweets. The analysis
captures tone, vocabulary, sentence patterns, post length, and recurring
structures. Use those patterns when a composer needs a consistent writing
baseline.

This route owns cache creation and refreshes. It can reuse a fresh profile
without another X request. An older or missing profile triggers a new tweet
fetch. Use [Get Style](/api-reference/styles/get) when refreshes are unwanted.

Keep the returned profile identifier with the normalized username. Preserve
the analyzed tweet records and timestamps exactly as returned. A later compose
step can reference the style without repeating profile discovery.

Do not treat writing patterns as current tweet performance. Style analysis
describes how the account writes. Use
[Analyze Performance](/api-reference/styles/performance) to refresh likes,
reposts, quotes, replies, bookmarks, and views.

<Callout icon="circle-check" color="#16a34a">
  **Free** - does not consume credits
</Callout>
<Info>
  This endpoint uses a two-tier system. It returns cached styles under 7 days old for free. Missing or older styles refresh from X and consume credits.
</Info>

## Headers

## Body

<ParamField body="username" type="string" required>
  X username to analyze. 1-15 characters, alphanumeric and underscores only.
</ParamField>

## Response

### 200 OK (cached)

Returns cached style data when a fresh cache exists (less than 7 days old). Same response shape as 201 Created.

<ResponseField name="xUsername" type="string">Normalized X username (lowercase, no `@` prefix).</ResponseField>
<ResponseField name="tweetCount" type="number">Number of tweets fetched and cached.</ResponseField>
<ResponseField name="isOwnAccount" type="boolean">`true` if the user has set their [X identity](/api-reference/account/x-identity) to this account.</ResponseField>
<ResponseField name="fetchedAt" type="string">ISO 8601 timestamp when tweets were fetched from X.</ResponseField>
<ResponseField name="tweets" type="object[]">Array of cached tweets.</ResponseField>

### 201 Created

<ResponseField name="xUsername" type="string">Normalized X username (lowercase, no `@` prefix).</ResponseField>
<ResponseField name="tweetCount" type="number">Number of tweets fetched and cached.</ResponseField>
<ResponseField name="isOwnAccount" type="boolean">`true` if the user has set their [X identity](/api-reference/account/x-identity) to this account.</ResponseField>
<ResponseField name="fetchedAt" type="string">ISO 8601 timestamp when tweets were fetched from X.</ResponseField>
<ResponseField name="tweets" type="object[]">Array of cached tweets.</ResponseField>

Each tweet object contains:
- `id` (string) - Tweet ID
- `text` (string) - Tweet text content
- `authorUsername` (string) - Author's X username
- `createdAt` (string) - ISO 8601 timestamp
- `media` (object[], optional) - Media objects attached to the tweet

```json
{
  "xUsername": "elonmusk",
  "tweetCount": 20,
  "isOwnAccount": false,
  "fetchedAt": "2026-02-24T10:30:00.000Z",
  "tweets": [
    {
      "id": "1893456789012345678",
      "text": "The future is now.",
      "authorUsername": "elonmusk",
      "createdAt": "2026-02-24T14:22:00.000Z"
    }
  ]
}
```

### 400 Invalid Input

```json
{ "error": "invalid_input", "message": "Invalid or missing username" }
```
Invalid or missing username. Provide a valid X username.

### 401 Unauthenticated

```json
{ "error": "unauthenticated", "message": "Missing or invalid API key" }
```
Missing or invalid API key.

### 402 Credits Required

Possible error codes:

- `no_cached_style` - No cached style is available, and the balance cannot fund a refresh
- `insufficient_credits` - Insufficient credits

```json
{ "error": "no_cached_style", "message": "No cached style for @username. Share 5-10 example tweet texts, then save via PUT /api/v1/styles/username." }
```
Top up or subscribe from the [dashboard billing page](https://dashboard.xquik.com/en/account?tab=subscription).

### 429 Rate Limited

```json
{ "error": "rate_limit_exceeded", "message": "Too many requests. Try again later.", "retryAfter": 60 }
```
Too many requests. Wait for the `Retry-After` header before retrying.

<Tip>
  Cached style data remains available after a plan ends. Fresh analysis requires enough available credits.
</Tip>

<Info>
  If a cached style already exists for this username, it will be replaced with fresh data.
</Info>
