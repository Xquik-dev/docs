## Remove one follower intentionally

Use this route to remove a specific follower from a connected account. Resolve
the target user ID before approval. Display the username and profile name for
human confirmation. Usernames can change, while numeric IDs remain stable.

Create one idempotency key for this removal. Reuse it only for the same target,
account, and retry. Store the action ID with both account IDs.

Follower-removal workflows often cover:

- Removing an unwanted follower after moderation review.
- Enforcing an account-specific access policy.
- Cleaning a follower list from an approved case queue.
- Recording the moderator and reason outside the public request.

This action does not represent an unfollow. It changes who follows the acting
account. Use the unfollow route when the acting account follows the target.
