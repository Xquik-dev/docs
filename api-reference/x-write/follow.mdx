## Choose Follow

Use this route to create one following relationship from a connected account. It has follow-specific minute and daily limits. Use profile-image routes only for account appearance changes.

<Warning>
  **Action-specific rate limit:** Follow allows **20 requests per minute** and **400 per day** per account. The general write tier allows 120 per 60s. Exceeding either limit returns `429 Too Many Requests`.
</Warning>

## Follow a verified profile

Use this route after resolving the intended profile. Prefer the numeric user
ID when your workflow already has it. Show the current username, profile name,
and follower context before approval.

Assign a unique idempotency key to the follow decision. Reuse it only for an
exact network replay. Store the target ID, acting account, action ID, and
lifecycle state.

Follow workflows can support:

- Following a reviewed partner or customer account.
- Applying an approved list of profiles to one account.
- Recording relationship changes in a CRM activity stream.
- Preventing duplicate follows across concurrent workers.

Do not use this route for follower collection. Use the followers endpoint to
retrieve profile rows. Use the following endpoint to inspect existing outbound
relationships.
