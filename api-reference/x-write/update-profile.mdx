## Review profile text before publishing

Use this route for profile fields owned by the connected account. Send only
the fields that should change. Leave unrelated fields absent.

Present the final name, biography, location, and website during approval.
Check links and spelling before submission. Keep a copy of the previous values
when your workflow supports rollback.

Create one idempotency key for the exact field set. Generate a new key after
editing any value. Store the acting account, changed field names, action ID,
and lifecycle state.

Profile workflows may include:

- Updating a biography for an approved launch.
- Changing a website after link verification.
- Applying a reviewed location or display name.
- Restoring earlier text after a campaign ends.

Use the avatar and banner routes for images. Do not place private notes or
credentials in public profile fields.

| X profile text update column | Request or response source | Review rule |
| --- | --- | --- |
| Acting X account | Request `account` | Confirm the profile receiving the changes. |
| Display name | Request `name` | Review the final 50-character value. |
| Profile bio | Request `description` | Review the final 160-character value. |
| Location | Request `location` | Review the final 30-character value. |
| Website | Request `url` | Validate the public destination before submission. |
| Changed fields | Exact request keys | Leave unrelated profile fields absent. |
| Idempotency key | Request header | Create a new key after any text change. |
| Write action ID | Response `id` | Poll the matching lifecycle record. |

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key. Session cookie authentication is also supported. Generate a key from the [dashboard](https://xquik.com/dashboard).
</ParamField>

<ParamField header="Idempotency-Key" type="string" required>
  Unique key for this intended write. Reuse it only for an exact network replay.
</ParamField>

<ParamField header="Content-Type" type="string" required>
  Must be `application/json`.
</ParamField>

## Body

<ParamField body="account" type="string" required>
  X username or account ID of your connected account to act as.
</ParamField>

<ParamField body="name" type="string">
  Display name. Maximum 50 characters.
</ParamField>

<ParamField body="description" type="string">
  Profile bio. Maximum 160 characters.
</ParamField>

<ParamField body="location" type="string">
  Profile location. Maximum 30 characters.
</ParamField>

<ParamField body="url" type="string">
  Website URL. Must be a valid URL.
</ParamField>
