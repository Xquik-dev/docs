Use this endpoint after a write request returns `202 x_write_unconfirmed`. The original write may have been dispatched, so do not retry-send the same action until you inspect the status and verify the outcome.

<CodeGroup>
  ```bash cURL
  curl https://xquik.com/api/v1/x/write-actions/42 \
    -H "x-api-key: xq_YOUR_KEY_HERE" | jq
  ```

  ```javascript Node.js
  const writeActionId = "42";
  const response = await fetch(
    `https://xquik.com/api/v1/x/write-actions/${writeActionId}`,
    {
      headers: {
        "x-api-key": "xq_YOUR_KEY_HERE",
      },
    },
  );
  const status = await response.json();
  ```

  ```python Python
  import requests

  write_action_id = "42"
  response = requests.get(
      f"https://xquik.com/api/v1/x/write-actions/{write_action_id}",
      headers={"x-api-key": "xq_YOUR_KEY_HERE"},
  )
  status = response.json()
  ```
</CodeGroup>

## Headers

<ParamField header="x-api-key" type="string" required>
  Your API key. Session cookie authentication is also supported.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
  Write action ID returned by a pending write response.
</ParamField>

## Response

<Tabs>
  <Tab title="200 Success">
    <ResponseField name="writeActionId" type="string">Write action ID.</ResponseField>
    <ResponseField name="action" type="string">Write action type, such as `create_tweet`.</ResponseField>
    <ResponseField name="status" type="string">Current status: `success`, `failed`, or `pending_confirmation`.</ResponseField>
    <ResponseField name="tweetId" type="string">Tweet ID when the action created or confirmed a tweet.</ResponseField>
    <ResponseField name="messageId" type="string">Message ID when the action sent a DM.</ResponseField>
    <ResponseField name="targetId" type="string | null">Target user, tweet, or resource ID when available.</ResponseField>
    <ResponseField name="charged" type="boolean">Whether the original write action was charged.</ResponseField>
    <ResponseField name="sendDispatched" type="boolean">Whether the write was dispatched.</ResponseField>
    <ResponseField name="retryable" type="boolean">Always `false` for this status response.</ResponseField>
    <ResponseField name="confirmationAttempts" type="number">Number of confirmation attempts.</ResponseField>
    <ResponseField name="confirmationSource" type="string | null">Confirmation source when available.</ResponseField>
    <ResponseField name="createdAt" type="string">ISO timestamp for write action creation.</ResponseField>
    <ResponseField name="sendDispatchedAt" type="string">ISO timestamp for dispatch when available.</ResponseField>
    <ResponseField name="confirmationCheckedAt" type="string">ISO timestamp for the last confirmation check when available.</ResponseField>
    <ResponseField name="confirmedAt" type="string">ISO timestamp for confirmation when available.</ResponseField>
    <ResponseField name="message" type="string">Status or error message when available.</ResponseField>
