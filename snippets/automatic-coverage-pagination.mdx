<Info>
  Omit `mode` for automatic maximum coverage. Xquik combines available views
  within a short request window. It keeps the existing response shape and page
  size. Pass `next_cursor` back unchanged as `cursor`. Keep the same endpoint,
  target, query, and filters.
</Info>

Existing unprefixed cursors keep their legacy behavior. `after`, `limit`, and
`pageSize` aliases also keep working. Billing still counts only returned rows.
Use `mode=standard` only to force legacy single-view pagination.

If a cursor returns `409 coverage_cursor_unavailable`, wait for `Retry-After`.
Retry that page once. Restart without a cursor if it remains unavailable.
Deduplicate restarted results by `id`.
