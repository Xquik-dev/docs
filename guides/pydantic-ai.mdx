Build a Pydantic AI agent that can search tweets, hand off IDs and cursors, post tweets, replay stored monitor events, and run extraction jobs - connected to Xquik's MCP server with 3 lines of config.

## Choose Pydantic AI for typed agent boundaries

Use Pydantic AI when tool outputs must enter validated Python models. Connect
Xquik with an `MCPToolset`. Keep tweet and profile schemas in application
result types.

Validate every durable handoff. Preserve tweet IDs, user IDs, queries, cursors,
and media URLs. Reject a write plan that lacks the connected account or target
ID.

Defer tool loading when an agent needs only a small operation set. Prefix
tools when several MCP servers expose similar names. These controls make tool
selection easier to inspect.

Use dependencies for request-scoped policy and identity. Require approval
before post, like, repost, follow, or direct-message calls. Save action IDs and
lifecycle states outside the generated answer.

## Prerequisites

- Python 3.10+
- [Xquik API key](/x-api-quickstart) (`xq_...`)
- An LLM API key (Anthropic, OpenAI, or any Pydantic AI-supported provider)

## Full Example

```python
import asyncio
from pathlib import Path
from pydantic_ai import Agent
from pydantic_ai.mcp import MCPToolset

toolset = MCPToolset(
    "https://xquik.com/mcp",
    headers={"x-api-key": "xq_YOUR_KEY_HERE"},
)

agent = Agent(
    "anthropic:claude-sonnet-4-6",
    toolsets=[toolset],
    instructions="You help users interact with X (Twitter) via the Xquik API.",
)


async def main():
    prompt = (
        "Search for the latest tweets about AI agents. Return compact JSON "
        "with query, route_used, tweets[{tweet_id,text,author_username,created_at}], "
        "has_more, next_cursor, and key influencers."
    )
    result = await agent.run(prompt)
    Path("xquik-pydantic-ai-handoff.json").write_text(
        result.output,
        encoding="utf-8",
    )


asyncio.run(main())
```

The agent discovers both Xquik tools and can call 119 MCP-compatible JSON or text operations.

Pydantic AI registers `MCPToolset` as an agent `toolsets` entry. A URL that does not end in `/sse` uses Streamable HTTP automatically. The MCP runtime returns normalized snake_case fields through `xquik.request()`. Keep prompts aligned with `tweet_id`, `has_more`, `next_cursor`, and returned job IDs.

  <Card title="Tweet search rows" icon="search">
    Store `tweet_id`, `text`, `author_username`, `created_at`, `has_more`, `next_cursor`, and the original `q`.
  </Card>
  <Card title="User profile rows" icon="users">
    Store source `id` as `user_id`, plus `username`, `name`, `followers`, `verified`, `profile_picture`, `has_more`, `next_cursor`, and the source lookup or search query.
  </Card>
  <Card title="Trend rows" icon="trending-up">
    Store each trend `name`, `rank`, `query`, and `description`. Keep response `count`, `woeid`, and the requested region with the run checkpoint.
  </Card>
  <Card title="Monitor and webhook setup" icon="radio">

  </Card>
  <Card title="Stored event replay" icon="activity">

  </Card>

    Store `extraction_id`, `status`, `poll`, and `export_after_complete`; poll before loading CSV, JSON, or XLSX rows.

## Reusing Connections

Wrap multiple calls in `async with agent` to keep the MCP connection open across requests:

```python
from pathlib import Path

async def main():
    async with agent:
        profile = await agent.run("Look up @username's public profile")
        tweets = await agent.run(
            "Get @username's latest 5 tweets. Return compact JSON with "
            "tweet_id, author_username, text, created_at, has_more, next_cursor, "
            "and route_used."
        )

    Path("xquik-pydantic-ai-profile.json").write_text(
        profile.output,
        encoding="utf-8",
    )
    Path("xquik-pydantic-ai-tweets.json").write_text(
        tweets.output,
        encoding="utf-8",
    )
```

## Deferred Tool Loading

For large tool sets, use `DeferredLoadingToolset` to hide tools from the model until they're discovered via tool search. This reduces prompt token usage:

```python
from pydantic_ai import Agent
from pydantic_ai.mcp import MCPToolset

toolset = MCPToolset(
    "https://xquik.com/mcp",
    headers={"x-api-key": "xq_YOUR_KEY_HERE"},
)

agent = Agent(
    "anthropic:claude-sonnet-4-6",
    toolsets=[toolset.defer_loading()],
)
```

## Loading from JSON Config

If you manage MCP servers via a config file:

```json mcp_config.json
{
  "mcpServers": {
    "xquik": {
      "url": "https://xquik.com/mcp",
      "headers": {
        "x-api-key": "xq_YOUR_KEY_HERE"
      }
    }
  }
}
```

```python
from pydantic_ai import Agent
from pydantic_ai.mcp import load_mcp_toolsets

toolsets = load_mcp_toolsets("mcp_config.json")
agent = Agent("anthropic:claude-sonnet-4-6", toolsets=toolsets)
```

## Tool Prefixes

Avoid naming conflicts when connecting multiple MCP servers:

```python
from pydantic_ai.mcp import MCPToolset

xquik = MCPToolset(
    "https://xquik.com/mcp",
    headers={"x-api-key": "xq_YOUR_KEY_HERE"},
).prefixed("xquik")
# Tools become: xquik_explore, xquik_xquik, etc.
```
