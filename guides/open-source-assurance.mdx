This repository is a shared project site.

It documents and disseminates 17 standalone Xquik open-source projects.

OpenSSF assigns badges to projects, not automatically to every supporting repository.

Therefore, `xquik-docs` has no separate badge entry.

This classification follows the official [project terminology](https://www.bestpractices.dev/en/criteria_discussion#terminology).

Create a separate entry if this repository independently releases software.

## Evidence

The [organization evidence register](https://github.com/Xquik-dev/.github/blob/main/OPENSSF.md) maps every standalone project.

Each project has its own live bestpractices.dev entry.

This shared site maintains these supporting controls:

| Control | Public Evidence |
| --- | --- |
| API contract | `openapi.yaml` matches the public application contract |
| Documentation tests | Agent, metadata, navigation, contract, and content tests |
| Site validation | Pinned validation and broken-link checks |
| Supply chain | Exact dependencies, integrity hashes, audits, and license policy |
| Repository licensing | REUSE 3.3 metadata covers every committed file |
| Vulnerability handling | [Private reporting and response targets](/security) |
| Change review | [Shared review policy](https://github.com/Xquik-dev/.github/blob/main/REVIEWING.md) |

## Remaining Gold Requirements

Technical checks cannot satisfy every Gold criterion.

The organization still needs:

- A bus factor of 2 or more
- Two unassociated significant contributors per project
- Independent review for at least 50% of released modifications
- A human security review completed within the last 5 years

Do not claim Gold until each project has verified public evidence.

Use the [current Gold criteria](https://www.bestpractices.dev/en/criteria/2) for reassessment.
