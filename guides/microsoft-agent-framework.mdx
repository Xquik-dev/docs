Build a Microsoft Agent Framework agent that can search tweets, hand off IDs and cursors, post tweets, replay stored monitor events, and run extraction jobs - all through Xquik's MCP server.

## Prerequisites

- Python 3.10+
- [Xquik API key](/quickstart) (`xq_...`)
- An LLM API key (OpenAI, Azure OpenAI, or any supported provider)

## Install

```bash
pip install agent-framework
```

The `agent-framework` meta-package installs the core framework, providers, and
MCP support.

## Full Example

```python
import asyncio
import os
from pathlib import Path
from agent_framework import Agent, MCPStreamableHTTPTool
from agent_framework.openai import OpenAIChatClient


async def main():
    async with Agent(
        client=OpenAIChatClient(model="gpt-4o"),
        name="xquik_agent",
        instructions="You help users interact with X through the Xquik API.",
        tools=MCPStreamableHTTPTool(
            name="xquik",
            url="https://xquik.com/mcp",
            description="X data platform with 119 MCP-compatible operations",
            header_provider=lambda kwargs: {
                "x-api-key": kwargs["xquik_api_key"],
            },
        ),
    ) as agent:
        handoff_prompt = (
            "Search for tweets about AI agents. Return compact JSON with "
            "query, route_used, tweets[{tweet_id,text,author_username,created_at}], "
            "has_more, next_cursor."
        )
        response = await agent.run(
            handoff_prompt,
            function_invocation_kwargs={
                "xquik_api_key": os.environ["XQUIK_API_KEY"],
            },
        )
        Path("xquik-agent-handoff.json").write_text(response.text, encoding="utf-8")


asyncio.run(main())
```

The agent discovers `explore` and `xquik`. It can call 119 MCP-compatible JSON or text operations. The MCP runtime returns normalized snake_case fields through `xquik.request()`. Keep prompts aligned with `tweet_id`, `has_more`, `next_cursor`, and returned job IDs.

## Handoff Checklist

  <Card title="Tweet search rows" icon="search">
    Store `tweet_id`, `text`, `author_username`, `created_at`, `has_more`, `next_cursor`, and the original `q`.
  </Card>
  <Card title="User profile rows" icon="users">
    Store source `id` as `user_id`, plus `username`, `name`, `followers`, `verified`, `profile_picture`, `has_more`, `next_cursor`, and the source lookup or search query.
  </Card>
  <Card title="Trend rows" icon="trending-up">
    Store each trend `name`, `rank`, `query`, and `description`. Keep response `count`, `woeid`, and the requested region with the run checkpoint.
  </Card>
  <Card title="Monitor and webhook setup" icon="radio">
    Store the returned monitor `id` as `monitor_id`, `event_types`, `next_billing_at`, the returned webhook `id` as `webhook_id`, `url`, and the one-time `secret` in a secret manager. On production deliveries, store `delivery_id` for receiver retry de-dupe and `stream_event_id` when one monitor event should process once across endpoint changes.
  </Card>
  <Card title="Stored event replay" icon="activity">
    Store `event_id`, `type`, `monitor_id`, `monitor_type`, `occurred_at`, `has_more`, `next_cursor`, and the `after` query for the next page.
  </Card>
  <Card title="Extraction jobs" icon="database">
    Store `extraction_id`, `status`, `poll`, and `export_after_complete`; poll before loading CSV, JSON, or XLSX rows.
  </Card>
  <Card title="Writes" icon="send">
    Store `tweet_id` or `write_action_id`, `reply_to_tweet_id`, `status`, `charged_credits`, and `poll`; do not resend pending writes.
  </Card>

## Streaming Responses

Pass `stream=True` to `run` for real-time token streaming:

```python
async with agent:
    async for update in agent.run(
        "What are the trending topics on X right now?",
        stream=True,
        function_invocation_kwargs={"xquik_api_key": xquik_api_key},
    ):
        if update.text:
            print(update.text, end="")
```

## Multi-Agent Handoff

Keep data access in one agent, then pass its compact result to a separate
analysis agent. This makes the MCP credential boundary explicit.

```python
import asyncio
import os
from pathlib import Path
from agent_framework import Agent, MCPStreamableHTTPTool
from agent_framework.openai import OpenAIChatClient


async def main():
    client = OpenAIChatClient(model="gpt-4o")
    researcher = Agent(
        client=client,
        name="researcher",
        instructions=(
            "Search X. Return compact JSON with "
            "tweet_id, author_username, text, created_at, has_more, next_cursor, "
            "and route_used."
        ),
        tools=MCPStreamableHTTPTool(
            name="xquik",
            url="https://xquik.com/mcp",
            header_provider=lambda kwargs: {
                "x-api-key": kwargs["xquik_api_key"],
            },
        ),
    )
    analyst = Agent(
        client=client,
        name="analyst",
        instructions="Analyze supplied X data. Do not fetch additional data.",
    )

    async with researcher, analyst:
        research = await researcher.run(
            "Find the top 10 most engaged tweets about AI agents.",
            function_invocation_kwargs={
                "xquik_api_key": os.environ["XQUIK_API_KEY"],
            },
        )
        result = await analyst.run(
            "Analyze sentiment and key themes in this JSON:\n" + research.text
        )
        Path("xquik-agent-workflow-handoff.json").write_text(
            result.text,
            encoding="utf-8",
        )


asyncio.run(main())
```

## Per-Run Headers

Pass API keys through `header_provider` and `function_invocation_kwargs` for
multi-tenant apps. The key remains scoped to the current run.

```python
mcp_tool = MCPStreamableHTTPTool(
    name="xquik",
    url="https://xquik.com/mcp",
    description="X data platform",
    header_provider=lambda kwargs: {
        "x-api-key": kwargs["xquik_api_key"],
    },
)

async with Agent(
    client=OpenAIChatClient(model="gpt-4o"),
    name="xquik_agent",
    instructions="You help users interact with X through the Xquik API.",
    tools=mcp_tool,
) as agent:
    response = await agent.run(
        "Search for tweets about AI agents",
        function_invocation_kwargs={"xquik_api_key": user_api_key},
    )
```

Do not close over a shared user's key in `header_provider`. Resolve it from the
current call's `function_invocation_kwargs`.

## Azure OpenAI

Use the same `OpenAIChatClient` with explicit Azure routing inputs:

```python
import os

from agent_framework import Agent
from agent_framework.openai import OpenAIChatClient

client = OpenAIChatClient(
    model=os.environ["AZURE_OPENAI_CHAT_MODEL"],
    azure_endpoint=os.environ["AZURE_OPENAI_ENDPOINT"],
    api_version=os.environ["AZURE_OPENAI_API_VERSION"],
    api_key=os.environ["AZURE_OPENAI_API_KEY"],
)

agent = Agent(
    client=client,
    name="xquik_agent",
    instructions="You help users interact with X through the Xquik API.",
    tools=mcp_tool,
)
```

## Environment Variables

Store your API keys in a `.env` file instead of hardcoding them:

```bash .env
XQUIK_API_KEY=xq_YOUR_KEY_HERE
OPENAI_API_KEY=sk-...
```

```python
import os
from dotenv import load_dotenv
from agent_framework import Agent, MCPStreamableHTTPTool
from agent_framework.openai import OpenAIChatClient

load_dotenv()

mcp_tool = MCPStreamableHTTPTool(
    name="xquik",
    url="https://xquik.com/mcp",
    header_provider=lambda kwargs: {
        "x-api-key": kwargs["xquik_api_key"],
    },
    description="X data platform",
)

agent = Agent(
    client=OpenAIChatClient(model="gpt-4o"),
    tools=mcp_tool,
)
```
