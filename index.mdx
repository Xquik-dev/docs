Use Xquik as a tweet scraper and X API alternative. Its X (Twitter) scraper API
searches tweets, can scrape follower lists and replies, and retrieves profiles
and timelines. Post tweets, upload media, monitor tweets every 1 second, track
profile changes, send signed webhooks, and connect SDKs or MCP. Accountless
guest wallets cover 33 prepaid GET reads. Seven fixed-price operations also
accept direct MPP.

## Copy-ready X tasks

Use these after you create an API key. Each call returns JSON you can send to an app, agent, spreadsheet job, webhook worker, or dashboard.

### Search tweets

Returns `tweets`, `has_next_page`, and `next_cursor`. Omit `mode` for automatic
maximum coverage. Pass `next_cursor` back unchanged as `cursor`. Search supports
X operators such as `from:username`, `since:YYYY-MM-DD`, `until:YYYY-MM-DD`,
hashtags, phrases, and `OR`.
Cost: 1 credit per tweet returned.

```bash
curl -G https://xquik.com/api/v1/x/tweets/search \
  --data-urlencode "q=from:username giveaway" \
  --data-urlencode "queryType=Latest" \
  --data-urlencode "limit=50" \
  -H "x-api-key: xq_your_api_key_here" | jq
```

```json
{
  "tweets": [
    {
      "id": "1780000000000000000",
      "text": "Giveaway entry is open.",
      "createdAt": "2026-05-08T04:00:00Z",
      "likeCount": 42,
      "retweetCount": 5,
      "replyCount": 3,
      "author": {
        "id": "9876543210",
        "username": "username",
        "name": "Xquik"
      }
    }
  ],
  "has_next_page": true,
  "next_cursor": "DAACCgACGRElMJcAAA"
}
```

### List followers

Returns `users`, `has_next_page`, and `next_cursor`. Omit `mode` for automatic
maximum coverage. Pass `next_cursor` back unchanged as `cursor`. Use `pageSize`
to cap each page between 20 and 200 users. Cost: 1 credit per follower returned.

```bash
curl -G https://xquik.com/api/v1/x/users/username/followers \
  --data-urlencode "pageSize=50" \
  -H "x-api-key: xq_your_api_key_here" | jq
```

```json
{
  "users": [
    {
      "id": "9876543210",
      "username": "username",
      "name": "Xquik",
      "followers": 10000,
      "following": 500,
      "verified": true
    }
  ],
  "has_next_page": true,
  "next_cursor": "DAACCgACGRElMJcAAA"
}
```

### Upload media from a URL

Returns `mediaId` for DMs and `mediaUrl` for tweet `media` arrays. URL uploads are useful for agents and workflow tools that pass files by HTTPS URL. Cost: 10 credits per upload.

```bash
curl -X POST https://xquik.com/api/v1/x/media \
  -H "x-api-key: xq_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{"account": "myxhandle", "url": "https://example.com/image.png"}' | jq
```

```json
{
  "success": true,
  "mediaId": "1893726451023847424",
  "mediaUrl": "https://media.xquik.com/uploads/1893726451023847424.png"
}
```

## Use Xquik with AI agents

Give agents a docs index first, then choose the execution path:

- Use [llms.txt](/llms.txt) when an agent needs to find the right API, SDK, MCP, webhook, or billing page.
- Use the [Context7 library](https://context7.com/xquik-dev/xquik-docs) when your coding environment supports Context7 docs lookup.
- Install the [Xquik Skill](https://github.com/Xquik-dev/x-twitter-scraper) when the agent writes code for tweet search, follower exports, media uploads, DMs, monitors, or webhooks.
- Connect API MCP v2.6.32 at `https://xquik.com/mcp` for authenticated tasks. Use the [current client path](/mcp/overview#client-compatibility) for OAuth, API-key fallback, or an adapter. Full credentials expose 118 catalog routes. Guest `paid_reads` keys expose 33 GET routes.

```bash
npx skills add Xquik-dev/x-twitter-scraper
```

## For developers

Xquik provides 6 integration methods:

<Steps>
  <Step title="REST API v1">
    Create monitors, query events, and manage webhooks programmatically. Authenticate with API keys via the `x-api-key` header.
  </Step>
  <Step title="HMAC webhooks">
    Receive monitor events at your HTTPS endpoint. Every delivery uses an HMAC-SHA256 signature.
  </Step>
  <Step title="MCP server">
    Connect AI agents through API MCP v2.6.32. Use OAuth 2.1 where supported. Otherwise, use the [documented client fallback](/mcp/overview#client-compatibility). Streamable HTTP exposes 2 tools. `explore` searches. `xquik` runs authenticated calls with normalized snake_case results.
  </Step>
  <Step title="AI agent skill">
    Install the [Xquik Skill](https://github.com/Xquik-dev/x-twitter-scraper) in Claude Code, Cursor, Codex, Copilot, Windsurf, or another compatible agent. It covers the Xquik API, MCP tools, and 129 REST operations. Run `npx skills add Xquik-dev/x-twitter-scraper`.
  </Step>
  <Step title="Guest wallets">
    Prepay 33 eligible GET routes without an account. Confirm $10-$250 USD, create a hosted checkout through REST, then wait for payment verification before using the `paid_reads` key.
  </Step>
  <Step title="Machine Payments Protocol">
    Pay per API call without subscribing. Seven fixed-price read operations accept MPP payments through Tempo (USDC). See the [MPP overview](/mpp/machine-payments-protocol) for operations and pricing.
  </Step>
</Steps>
