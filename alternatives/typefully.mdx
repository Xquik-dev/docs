## Source-backed Typefully scope

Typefully's official X scheduling page describes AI writing help, X post and thread scheduling, natural-language scheduling, predefined time slots, and a content calendar. It supports cross-posting to LinkedIn, Threads, Bluesky, and other platforms. It also covers X analytics, multiple accounts, team collaboration, polls, media, long posts, realistic previews, auto-plugs, and automatic thread splitting.

Typefully's REST API creates, edits, schedules, publishes, and deletes drafts. It posts to X, LinkedIn, Threads, Bluesky, and Mastodon. Media uploads accept images, videos, GIFs, and PDFs. The API supports tags, social sets, draft comments, and webhooks for created, published, scheduled, status-changed, tag-changed, and deleted drafts. Its MCP actions cover drafts, queues, published posts, media, tags, and connected accounts.

Typefully's help pages describe saved slots, suggested X posting times, Natural Posting Times with up to 4 minutes of variation, calendar views, drag-and-drop changes, tags, and minimum gaps. X analytics include impressions, engagements, engagement rate, profile conversion rate, and CSV exports. Auto-DM can trigger on replies, retweets, or follows. The published limits allow 3 campaigns, 30 DMs/minute, 100 DMs/hour, 500 DMs/day, and 4 days per campaign.

## Migration path

Do not move the whole creator calendar first. Keep Typefully for writing, X thread scheduling, cross-posting, draft comments, analytics, Auto-DMs, and content workflow automation if that is already the operating model. Move one X-only task when the output must become API data, files, signed webhooks, or MCP tool results.

Keep the test small: one task, one output, one cost model, and one downstream owner. Use Xquik for the X work that needs tweet search, follower export, post actions, media uploads, DMs, monitor tweets, webhook delivery, SDK calls, or MCP.

Price the real workload. On Xquik, Starter is USD 20/month with 140,000 credits. Top-ups are USD 0.00015/credit, webhook and stored-event management are free, and active monitors bill only while enabled.
